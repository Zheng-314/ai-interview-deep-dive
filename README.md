# 深挖面试官（AI Interview Deep Dive）

一个面向校招学生的 **AI 模拟面试工具**：上传目标岗位 JD 和简历，AI 面试官带你走完真实面试流程——自我介绍、项目讲解、岗位场景追问——结束后生成一份可下载的 HTML 复盘报告。

## 它解决什么问题

学生面试前最大的问题不是没题刷，而是**没人追着问**：简历上的项目自己讲得通，被面试官追问两层就崩。通用大模型随机提问、不停换题，练不到"被深挖"的肌肉。

**深挖面试官的做法：**

- **固定真实流程**：自我介绍 1 轮 → 项目讲解 5 轮 → 岗位场景追问 5 轮 → 总结与建议 1 轮，共 11 轮
- **顺着回答往下追**：显式状态机维护追问深度（浅/中/深）、当前主题与已覆盖考点，问题基于你上一轮的回答递进，不平行换题
- **双岗位方向**：产品面（用户洞察、需求验证、优先级、指标）与技术面（架构、选型、实现、性能）追问焦点不同
- **双氛围**：完整面试（正式节奏）/ 轻松面试（温和引导、先认可再追问，适合第一次面试的同学）
- **真诚的复盘报告**：逐轮待改进点、按主题去重的优先补强清单、面试官的肯定与鼓励，而不是简单复述

## 功能

- JD / 简历上传（PDF 拖拽上传 + 文本粘贴兜底；不做假 OCR，图片会诚实提示）
- AI 面试官数字人：呼吸、眨眼、思考光环、朗读口型动画
- 问题语音播报（浏览器 speechSynthesis）+ 语音回答（Web Speech API，Chrome/Edge）
- 摄像头画面（仅本地，不上传不录像），面试间画中画
- 刷新不丢进度（sessionStorage 会话恢复）
- 模型输出稳定性：JSON 解析失败自动重试 + 降级解析，阶段切换永不出空问题

## 技术栈

Next.js 16（App Router，Turbopack）· React 19 · TypeScript · DeepSeek API · pdf-parse

## 快速开始

```bash
npm install
cp .env.example .env.local   # 填入你的 DEEPSEEK_API_KEY
npm run dev                  # http://localhost:3000
```

## 测试与评测

```bash
npm test               # 9 条单元测试：流程状态机、空问题防御、脏 JSON 解析、报告生成等
npm run build          # 生产构建（Turbopack）
node scripts/eval.js   # 自动评测：真实跑完整 11 轮面试链路，统计完成率/耗时/深度递进
```

最近一次自动评测（本地，3 次完整面试）：链路完成率 3/3，36 轮 0 空问题 0 降级，追问深度呈现 开场→浅→中→深 的递进结构。

## 隐私

- JD、简历与面试记录不上传存储，会话仅保存在你的浏览器 sessionStorage
- 摄像头画面只在本机渲染，不录像、不回传
- API Key 只在服务端环境变量读取，不进入浏览器
